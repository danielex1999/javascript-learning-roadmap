# JavaScript en la actualidad — Resumen

## Evolución del propósito de JavaScript
Originalmente, JavaScript nació para enviar información **lo más procesada posible al servidor**, de modo que este solo trabajara con peticiones válidas.  
Sin embargo, **hoy en día su rol es mucho más amplio**.

## JavaScript como estándar de la web
Actualmente, JavaScript es prácticamente un **monopolio en el desarrollo web**.

- No importa si el backend está hecho en PHP, Java o Python
- En el 99% de las aplicaciones web, se necesita JavaScript

## Más allá del navegador
Antes, JavaScript solo podía ejecutarse dentro del navegador.  
Con tecnologías como **Node.js**, JavaScript ahora puede ejecutarse **en el servidor**, de forma independiente.

## Usos principales de JavaScript

### Aplicaciones web
JavaScript se utiliza para:
- Dashboards administrativos
- Animaciones
- Gráficas y cálculos
- Información en tiempo real
- Interacción con el usuario

### Google Maps como ejemplo
Google Maps es un claro ejemplo del poder de JavaScript:
- Animaciones
- Zoom
- Movimiento del mapa
- Cálculos en tiempo real
Todo esto se ejecuta principalmente con JavaScript, junto con otras tecnologías como CSS.

### Presentaciones web
JavaScript permite crear presentaciones interactivas y ligeras, como las hechas con **Reveal.js**:
- Animaciones fluidas
- Menor peso que presentaciones tradicionales (ej. PowerPoint)
- Ejecución directa en el navegador

### Servidores web con Node.js
Con JavaScript y Node.js se pueden crear:
- Servidores web
- Manejo de peticiones HTTP
- Acceso al sistema de archivos
- Conexión a bases de datos
- Comunicación en tiempo real con sockets

### Videojuegos
JavaScript también permite crear videojuegos completos:
- Animaciones 2D y 3D
- Manejo de eventos (teclado y mouse)
- Efectos de luz
- Juegos extremadamente ligeros (menos de 50 KB)

### Aplicaciones móviles
Usando frameworks como:
- Ionic
- React Native
- NativeScript

Se pueden crear aplicaciones móviles instalables utilizando conocimientos de JavaScript.

### Aplicaciones de escritorio
Con tecnologías como **Electron**, JavaScript permite crear aplicaciones nativas para:
- Windows
- Linux
- macOS

## Frameworks y librerías
Existen múltiples frameworks y librerías que facilitan el desarrollo con JavaScript, como:
- Angular
- Vue
- React

Aunque elegir entre ellos puede ser difícil, **JavaScript sigue siendo el mismo**, por lo que dominar sus fundamentos hace que aprender cualquier framework sea mucho más sencillo.
