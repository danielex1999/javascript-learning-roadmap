# Historia de JavaScript - Resumen

## JavaScript ≠ Java
JavaScript y Java **no son el mismo lenguaje**.  
Son lenguajes distintos, se ejecutan de manera diferente y tienen propósitos distintos.  
Entender esta diferencia es clave para evitar confusiones al buscar información.

## Contexto histórico
A inicios de los años 90, la velocidad de los módems era muy limitada (28 kbps).  
Esto permitió crear páginas web un poco más complejas, pero también trajo nuevos problemas, especialmente con **formularios web**.

## Problema del lado del servidor
En ese momento, todo el procesamiento se hacía en el servidor:
- El usuario enviaba un formulario
- El servidor validaba los datos
- Si había errores, devolvía toda la página nuevamente

Este proceso generaba **mucho tráfico innecesario**, sobre todo cuando había muchos usuarios.

## Nacimiento de JavaScript
Para solucionar esto, surgió la necesidad de un lenguaje que se ejecutara **del lado del cliente**.  
Así nació JavaScript, creado por **Brendan Eich**, empleado de Netscape.

- Nombre original: **LiveScript**
- Fue renombrado a **JavaScript** por razones de marketing, aprovechando la popularidad de Java (aunque no están relacionados).

## Estandarización
Otras empresas, como Microsoft, crearon sus propias versiones del lenguaje.  
Para evitar conflictos, en **1997** se decidió estandarizarlo.

- Se creó el comité **TC39**
- Se definió el estándar **ECMA-262**
- El lenguaje pasó a llamarse oficialmente **ECMAScript**

JavaScript es la implementación más conocida de este estándar.

## Importancia actual
JavaScript permitió:
- Validaciones en el navegador
- Menor carga en los servidores
- Aplicaciones web más dinámicas

Hoy en día, es **uno de los lenguajes de programación más usados del mundo**.
